# Data Model (Proposed)

These are internal execution/derived-state entities, not new resource envelopes. Existing ObjectMeta, catalog references, status and watch events retain their owners.

| Entity | Fields and validation | Ownership/lifecycle |
| --- | --- | --- |
| QueryDocument | language major, typed predicate AST, optional retrieval, ordered sort, canonical fingerprint. Limits charged before allocation/recursion. | API parser; request lifetime. |
| TermRegistration | canonical path, value type/operators, supported API surfaces/operations, authorization hook, durable-fact/index requirements, semantic version, compiler. | One source-owned API registry; rejects duplicate paths/ambiguous compilers. |
| ProviderDescriptor | stable internal ID/revision, supported API-surface/kind/operation combinations, modes/order/pagination strategy, index/model revision and readiness, finite budgets. | Shared advanced-query/generic-search provider contract; not a second discovery model or App grant. |
| QueryPlan | API surface, authorized namespace/parent or trusted publication-target/revision and principal binding, typed source predicates, whole-plan capability ID/revision, index/provider route, order, bounds. | Compiler; fail closed before execution if no eligible full plan. |
| PageCursor | envelope version/key ID, query fingerprint, kind set, API surface, namespace/parent UID or trusted publication-target/revision, authorization-context binding, registry/index/model revision, position or window ID/ordinal, issued/expiry time, MAC. | API boundary; opaque base64url authenticated bytes, shared key ring. No raw query/private context encoded. |
| SearchItemConnection / SearchItem | One edges/PageInfo container; edge node union of canonical Product/Category/ProductVariant objects. Kind set/common scoring order bound to continuation; tie-break by kind then UID after requested order. | Generic search; same provider registry as advanced typed queries. |
| RankedWindow | random ID, API surface/owner binding, publication identity where applicable, scope/query/plan revisions, ordered <=1,000 kind/UID identities with captured authoritative resource versions and stable tie values, expiry, quota slot references, state. | Shared Scylla TTL; memdb implements same contract for tests only. No full resource payload, embeddings or plaintext private context. |
| WindowQuotaSlot | deployment slot ID, principal-scope slot ID, window ID, lease expiry, CAS version. | Shared conditional allocation; fixed 20,000 global/2,048 principal-scope slots. Acquire deterministically, release partial claims on failure, expired claims reclaimable. |
| ProviderIndexDocument | canonical kind/UID/namespace, source resourceVersion, API audience/publication revision, allowed searchable fields, index/model revision and deletion marker. | Derived provider projection; excludes credentials/private recommendation context. Schema/version allowlist per kind/API surface; published projections must not hydrate or expose Admin drafts. |
| LabelPosting | namespace/kind/key/value-or-exists marker/shard, canonical sort timestamp/UID, source version. | Derived indexed projection; ledger-tracked prior keys, authoritative refresh, idempotent replay, rebuild audit before ready. |
| ProjectionIdentity | kind/namespace/name, current UID and resource version, prior provider document/posting keys, journal epoch/sequence, deletion tombstone and index revision. | Durable projection ledger; resolves UID-less namespaced journal deletions and recreation. Backend I/O failures are not resource absence. |
| ControllerQueryIdentity | canonical server fingerprint/language revision, exact configured query and namespace/kind/parent binding alongside existing disk checkpoint schema version. | Per-replica checkpoint; query changes cause controlled cold relist, retaining pending admitted work and existing checkpoint migration rules. |

## State transitions

- Registry/provider: registered -> validating/index-building -> ready; failure/revision change -> unavailable until revalidated. Installation is insufficient evidence. Public readiness is safe/aggregate, not private endpoint detail.
- Window: quota allocated -> building -> atomically ready -> expired/invalidated -> reclaimed. Building/error windows cannot serve pages. Publish only after complete bounded candidate order is stored; no partially built result. Expiry is absolute and reads do not extend it.
- Index updates: durable admitted event -> bounded authoritative identity refresh and ledger reconciliation -> idempotent provider/posting update -> persisted source checkpoint. Namespaced deletion events do not carry UID/version; use the ledger and authoritative point lookup, not a fabricated deletion payload. An existing/recreated resource upserts its current UID/version; authoritative absence deletes the ledger's prior UID/postings and retains a tombstone. Retry lookup/write errors without checkpoint advance. Rebuild uses bootstrap-before-list plus replay; reconcile replay against current authoritative state so an old update/delete cannot overwrite a newer bootstrap image or delete a recreation. Serialize each identity under the projection owner and persist progress only after external work completes; repeatable writes make crash replay safe. Retention expiry forces controlled rebuild before readiness. No claim of zero-lag snapshot search.
- Checkpoint predicate change: detect identity mismatch -> stop using cached membership as complete -> preserve pending/retry/quarantine work -> bootstrap/list/replay -> activate new identity. Never overlap checkpoint writers.

## Storage decisions

Use new forward migrations under the existing migration owner; read `.claude/rules/scylla-migrations.md` during implementation. Proposed tables `query_windows_by_id`, `query_window_slots_by_scope`, `resource_labels_by_value`, `resource_labels_by_key` and `query_projection_identities_by_name` follow existing query-first naming. Table details/TTL/consistency and idempotency tests belong to the implementation change; no schema is applied by planning. CAS slot acquisition is bounded, with no count scan. Shared window records bind principal/namespace even if the caller knows the random ID. Preserve ledger tombstones for at least the supported journal replay/rebuild horizon, independent of the short ranked-window TTL.

Label postings initially support equality/exists and bounded IN union for the same key (<=8 values). NOT/absence and arbitrary intersections require an eligible provider/declared indexed combination; they are not scanned. Mutable sort-key changes follow owning index semantics; authoritative list keyset paging is not advertised as an immutable snapshot. Provider ranked windows freeze result identities but still reauthorize/revalidate object existence/version at read; invalidation fails explicitly rather than silently filling gaps.
